## Setup

### 1. Database (PostgreSQL)

1. Install PostgreSQL and open pgAdmin 4.
2. Create a database named `product_db`.
3. In the Query Tool of `product_db`, run:
   ```sql
   CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
   ```

### 2. Environment file

Copy `.env.example` to `.env` and put your own PostgreSQL password in `DB_PASSWORD`:

```bash
copy .env.example .env      # Windows
# cp .env.example .env      # Mac / Linux
```

### 3. Install and run

```bash
pnpm install
pnpm run migration:run      # creates the products table
pnpm run start:dev          # starts the server on http://localhost:5001
```

(If `pnpm` is not installed: `npm install -g pnpm`.)

## Product fields

| Field    | Type    | Description                        |
|----------|---------|------------------------------------|
| id       | UUID    | Primary key generated by database  |
| name     | string  | Product name                       |
| category | string  | Product category                   |
| price    | number  | Product price                      |
| quantity | integer | Available stock quantity           |

## Endpoints

| Method | Endpoint        | Description                     | Success status |
|--------|-----------------|---------------------------------|----------------|
| POST   | /products       | Create and save a product       | 201            |
| GET    | /products       | Return all saved products       | 200            |
| GET    | /products/:id   | Return the product with the ID  | 200            |
| PATCH  | /products/:id   | Update the product with the ID  | 200            |
| DELETE | /products/:id   | Delete the product with the ID  | 200            |

Example `POST /products` body:

```json
{
  "name": "Pen",
  "category": "Stationery",
  "price": 10.5,
  "quantity": 50
}
```

Errors: `400` for invalid input or an invalid ID format, `404` when the product ID does not exist.
